大米加工企业安全管理信息系统

面向大米加工企业的「双重预防机制」数字化安全管理平台

风险分级管控 隐患排查治理 闭环管理 数据可视化
1项目简介

本系统面向大米加工企业，将国家推行的「安全生产双重预防机制」数字化落地，实现安全风险分级管控与隐患排查治理两大主线的全过程闭环管理，替代传统纸质台账，提升企业安全管理的标准化与信息化水平。

2行业痛点
⚠️
高风险环节多大米加工涉及粉尘防爆、机械伤害、有限空间等风险，事故后果严重
📄
管理依赖纸质台账风险辨识不系统、责任难落实、隐患整改难闭环
🧰
缺乏易用数字化工具国家持续推进双重预防机制建设，但企业缺少配套工具
3系统架构
Vue 3 Element Plus Spring Boot MyBatis-Plus JWT 登录鉴权 Apache POI 报表导出
🖥️ 前端 → Vue 3 + Element Plus（响应式界面）
🔌 后端 → Spring Boot + MyBatis-Plus（RESTful 接口）
🗄️ 数据 → 关系型数据库 + JWT 权限校验
4核心功能
主线一 · 安全风险分级管控
📋
风险识别清单风险点分级建档，红橙黄蓝四色可视化分级
🧮
LEC 评估法作业条件危险性分析，L/D/C 三因子量化风险等级
🟦
风险矩阵法评估多维度二次评估，与 LEC 法交叉验证
主线二 · 隐患排查治理
🔍
隐患排查检查任务派发与执行，隐患分级登记
📒
隐患治理台账隐患登记、定级、整改、验收全程留痕
♻️
闭环管理发现 → 整改 → 复查 → 销号，PDCA 闭环可追溯

支撑模块

👥安全责任制
⚙️设备设施管理
🎓安全培训管理
🚨应急管理
📚安全标准法规库
📊安全驾驶舱
5系统创新点
1
双重预防机制一体化落地风险管控 + 隐患治理两条主线在同一平台贯通
2
LEC 法 + 风险矩阵法双评估两种量化方法交叉验证，风险分级更科学可靠
3
隐患整改全流程闭环从发现到销号全程留痕、责任到人、可追溯
4
数据可视化安全驾驶舱安全态势、风险分布、隐患状态一屏掌握
